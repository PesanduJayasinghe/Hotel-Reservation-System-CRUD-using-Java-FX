# 🏨 Hotel Reservation System — JavaFX CRUD Application

A simple yet functional **Hotel Reservation Management System** built using **JavaFX**.  
This project demonstrates the use of **CRUD (Create, Read, Update, Delete)** operations, scene navigation, and clean MVC architecture in Java.

---

## ✨ Features

✅ **Add New Records** – Create new entries for staff, customers, and reservations  
✅ **View Records** – Display existing data in JavaFX `TableView`s  
✅ **Update Records** – Modify existing data interactively  
✅ **Delete Records** – Remove data safely from the list  
✅ **Scene Navigation** – Navigate between dashboard and different info screens  
✅ **Data Binding** – Automatically updates UI elements using JavaFX’s `ObservableList`  
✅ **MVC Pattern** – Organized code with separate Controller, Model, and View layers

---
